FLT.cond

Conditional fault

This instruction conditionally generates a Conditional fault exception. If an exception is generated, the immediate field is copied to ESR_ELx.

(FEAT_CFLT)

Encoding

FLT.<cond> #<imm>

Decode for this encoding

if !IsFeatureImplemented(FEAT_CFLT) then EndOfDecode(Decode_UNDEF); end; let imm : bits(16) = imm16; let condition : bits(4) = cond;
