SRLS

Scope release

This instruction signals to the memory system that if the next instruction in program order has Release semantics or is a DMB instruction that defines a Barrier scope with a preceding SLBND instruction, then these instructions do not create a Barrier-ordered-before relationship between any Effect in program order before the SLBND instruction and any of the following:

  • The Effect with Release semantics.
  • Any Effect in program order after the DMB Effect.

Assembler Symbols

STSHSTRM

Is a store shared stream hint, and is encoded in "op2[0]". If present, it additionally provides the same hint as the STSHH STRM instruction.

Note

If FEAT_PCDPHINT is not implemented, the optional STSHSTRM hint may not have the performance benefits that are associated with the hint generated by the STSHH STRM instruction.

0 [absent]
1 [present]
