CFLTGE (immediate)

Compare signed greater than or equal to immediate and fault

This instruction compares the signed value in a register with an immediate, and generates a Conditional fault exception if the register value is greater than or equal to the immediate. If an exception is generated, the <reason> operand is copied to ESR_ELx.

This instruction does not affect the condition flags.

This is a pseudo-instruction of CFLT<cc> (immediate). This means:

  • The encodings in this description are named to match the encodings of CFLT<cc> (immediate).
  • The assembler syntax is used only for assembly, and is not used on disassembly.
  • The description of CFLT<cc> (immediate) gives the operational pseudocode, any constrained unpredictable behavior, and any operational information for this instruction.

Encoding for the 32-bit greater than variant

Applies when (sf == 0)

CFLTGE #<reason>, <Wt>, #<immp1>

is equivalent to

CFLTGT #<reason>, <Wt>, #<imm>

Encoding for the 64-bit greater than variant

Applies when (sf == 1)

CFLTGE #<reason>, <Xt>, #<immp1>

is equivalent to

CFLTGT #<reason>, <Xt>, #<imm>

Assembler Symbols

<reason>

Is a 2-bit unsigned immediate, in the range 0 to 3, encoded in the "imm2" field.

<Wt>

Is the 32-bit name of the general-purpose register to be tested, encoded in the "Rt" field.

<immp1>

Is a signed immediate, in the range -255 to 256, encoded as "imm9h:imm9l" plus 1.

<Xt>

Is the 64-bit name of the general-purpose register to be tested, encoded in the "Rt" field.
