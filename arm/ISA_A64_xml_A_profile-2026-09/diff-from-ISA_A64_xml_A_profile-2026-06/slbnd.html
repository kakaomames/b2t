SLBND

Scoped release boundary

This instruction signals to the memory system that a corresponding instruction with Release semantics or DMB instruction will subsequently occur in program order, and if that corresponding instruction defines a Barrier scope with the SLBND instruction, then these instructions do not create a Barrier-ordered-before relationship between any Effect in program order before the SLBND instruction and any of the following:

  • The Effect with Release semantics.
  • Any Effect in program order after the DMB Effect.
