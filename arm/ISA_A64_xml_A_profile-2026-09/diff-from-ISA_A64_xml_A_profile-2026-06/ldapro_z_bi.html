LDAPRO

Load-Acquire RCpc octaword

This instruction loads thirty-two contiguous bytes to elements of a 256-bit (octaword) vector from the memory address generated by a 64-bit scalar base, plus a scaled immediate offset. The base register must be aligned to 32 bytes if alignment is checked.

This instruction is unpredicated.

The instruction has memory ordering semantics as described in Load-Acquire, Load-AcquirePC, and Store-Release.

This instruction requires that the Effective SVE vector length is at least 256 bits.

This instruction is illegal when executed in Streaming SVE mode, unless FEAT_SME_FA64 is implemented and enabled.

Encoding

LDAPRO <Zt>, [<Xn|SP>{, #<imm>}]

Decode for this encoding

if !IsFeatureImplemented(FEAT_SVE_LRCPC) then EndOfDecode(Decode_UNDEF); end; if MaxImplementedVL() < 256 then EndOfDecode(Decode_UNDEF); end; let t : integer = UInt(Zt); let n : integer = UInt(Rn); let imm : integer = UInt(imm8h::imm8l); let acquirepc : boolean = TRUE;

Assembler Symbols

<Zt>

Is the name of the scalable vector register to be transferred, encoded in the "Zt" field.

<Xn|SP>

Is the 64-bit name of the general-purpose base register or stack pointer, encoded in the "Rn" field.

<imm>

Is the optional positive immediate byte offset, a multiple of 32 in the range 0 to 8160, defaulting to 0, encoded in the "imm8h:imm8l" fields.

Operation

CheckNonStreamingSVEEnabled(); let VL : integer{} = CurrentVL(); if VL < 256 then EndOfDecode(Decode_UNDEF); end; var base : bits(64); let offset : integer = imm * 32; let tagchecked : boolean = n != 31; let accdesc : AccessDescriptor = CreateAccDescLDAcqPC(tagchecked, acquirepc, t); if n == 31 then CheckSPAlignment(); base = SP{64}(); else base = X{64}(n); end; let addr : bits(64) = AddressAdd(base, offset, accdesc); let data : bits(256) = Mem{256}(addr, accdesc); Z{VL}(t) = ZeroExtend{VL}(data);

Operational information

This instruction is a data-independent-time instruction as described in About PSTATE.DIT.
