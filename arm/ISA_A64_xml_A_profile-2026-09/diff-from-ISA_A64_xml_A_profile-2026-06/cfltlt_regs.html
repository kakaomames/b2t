CFLTLT (register)

Compare registers and fault if less than

This instruction compares the values in two registers, and generates a Conditional fault exception if the first value is less than the second. If an exception is generated, the <reason> operand is copied to ESR_ELx.

This instruction does not affect the condition flags.

This is a pseudo-instruction of CFLT<cc> (register). This means:

  • The encodings in this description are named to match the encodings of CFLT<cc> (register).
  • The assembler syntax is used only for assembly, and is not used on disassembly.
  • The description of CFLT<cc> (register) gives the operational pseudocode, any constrained unpredictable behavior, and any operational information for this instruction.

Encoding for the 32-bit greater than variant

Applies when (sf == 0)

CFLTLT #<reason>, <Wm|WSP>, <Wt|WSP>

is equivalent to

CFLTGT #<reason>, <Wt|WSP>, <Wm|WSP>

Encoding for the 64-bit greater than variant

Applies when (sf == 1)

CFLTLT #<reason>, <Xm|SP>, <Xt|SP>

is equivalent to

CFLTGT #<reason>, <Xt|SP>, <Xm|SP>

Assembler Symbols

<reason>

Is a 2-bit unsigned immediate, in the range 0 to 3, encoded in the "imm2" field.

<Wm|WSP>

Is the 32-bit name of the general-purpose register or stack pointer to be tested, encoded in the "Rm" field.

<Wt|WSP>

Is the 32-bit name of the second general-purpose source register or stack pointer, encoded in the "Rt" field.

<Xm|SP>

Is the 64-bit name of the general-purpose register or stack pointer to be tested, encoded in the "Rm" field.

<Xt|SP>

Is the 64-bit name of the second general-purpose source register or stack pointer, encoded in the "Rt" field.
